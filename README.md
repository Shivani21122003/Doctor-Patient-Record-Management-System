# Doctor-Patient-Record-Management-System
## 📌 Project Overview
The Doctor and Patient Record Management System is a database management project developed using MySQL to organize and analyze hospital records. It helps manage patient details, doctor information, departments, appointments, and consultation fees through SQL queries and views.

## 🎯 Objectives
- Organize patient, doctor, department, and appointment records.
- Retrieve meaningful information using SQL queries.
- Analyze patient visits, consultation fees, and appointment details.
- Simplify data retrieval using views.

## 🛠️ Technologies Used
- **Database:** MySQL
- **Language:** SQL
- **Concepts:** Joins, Aggregate Functions, GROUP BY, Subqueries, Filtering, Sorting, Views, Window Functions

## 📊 Key Features
- Retrieve patient records based on age and other conditions.
- Count patients by city.
- Identify cities with the highest number of patient visits.
- Retrieve female patients born in a specified city during 1991.
- Calculate consultation fees using `SUM()` and `AVG()`.
- Rank appointments based on consultation fees using `ROW_NUMBER()`, `RANK()`, and `DENSE_RANK()`.
- Create database views for simplified reporting.

## 💡 SQL Concepts Demonstrated
- `SELECT`, `WHERE`, `ORDER BY`
- `GROUP BY` and `HAVING`
- Aggregate functions: `COUNT()`, `SUM()`, `AVG()`
- Joins between related tables
- Subqueries
- Date-based filtering
- Window functions
- Views

## 📈 Key Learnings
- Designing and querying relational databases.
- Retrieving insights from healthcare-related data.
- Applying SQL functions to analyze hospital visits and consultation fees.
- Simplifying complex queries and improving data accessibility.
